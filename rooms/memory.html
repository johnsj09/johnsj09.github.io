Memory & Sleep

Rules, exceptions, and the night that sorts them.

My dissertation asked how one memory system can learn the rule and remember the exception. The next question is what sleep does with both.

18paintings in the museum task I designed
3rooms, with one rule-breaking painting in each

Two routes through one memory system

How does a brain learn a general rule and still remember the one case that breaks it? I tested this in C-HORSE, a neural network model of the hippocampus. Silence a pathway and see what it was doing.

Both pathways working. The model uses the season as a cue, switches between two conflicting rule sets, and avoids the catastrophic interference seen in single-system learners.

Solid line: trisynaptic pathway. Dashed line: monosynaptic pathway. Numbers are units per layer. Built in Emergent with contrastive Hebbian learning and theta-phase gating.

Where I'm heading: one night, stage by stage
